# 📖 Sobre o Projeto

O **Java Project** é um projeto desenvolvido com o objetivo de aprofundar conhecimentos na linguagem Java e aplicar conceitos fundamentais de desenvolvimento de software utilizando Programação Orientada a Objetos (POO).

O sistema foi estruturado para servir como base de estudos, prática e evolução contínua, permitindo a implementação de novas funcionalidades e melhorias ao longo do desenvolvimento.

Além disso, o projeto busca aplicar boas práticas de organização de código, separação de responsabilidades e arquitetura limpa, tornando o código mais legível, reutilizável e escalável.

---

# 🎯 Objetivos do Projeto

- Praticar desenvolvimento utilizando Java
- Aplicar conceitos de Programação Orientada a Objetos

# ▶️ Como Executar o Projeto

## 1️⃣ Clone o repositório

```bash
git clone https://github.com/Danilloschwager/javaproject.git
```

---

## 2️⃣ Acesse a pasta do projeto

```bash
cd javaproject
```

---

## 3️⃣ Compile o projeto

Caso esteja utilizando Maven:

```bash
mvn clean install
```

---

## 4️⃣ Execute a aplicação

```bash
mvn exec:java
```

Ou execute diretamente pela sua IDE de preferência.

---

# 🧪 Executando os Testes

Para rodar os testes automatizados utilize:

```bash
mvn test
```
